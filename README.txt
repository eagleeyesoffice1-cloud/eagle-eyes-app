EAGLE EYES RESTORATION — UPDATED DEMO
Open index.html in a desktop browser for a local preview. To install on Android as a PWA, files must be served from HTTPS hosting (not file://). No hosting is configured.

Implemented in this prototype:
- Three simulated role views (Owner, Office, Field)
- Employee directory with demo add/deactivate rules
- Office finance records, estimate upload and payment entry
- Owner-only discount edits in the demo UI
- Existing job records, photo storage, manual PDF print flow and collection aging
- Manifest and offline cache shell

IMPORTANT: THIS IS NOT A SECURE MULTIUSER APP.
- Roles can be changed by anyone; all checks are browser-side.
- No authentication, server authorization, shared cloud database, secure file storage, backups, SMS gateway or email delivery.
- Do not enter real customer, employee or financial information.
- Production requires secure server-side authorization and audit logs.
